1.1.0 更新日志:
1.新增「小天才应用设置」板块 — 插在「应用设置」和「设置」之间，板块数 5→6，含两个开关（默认均开启）。
2.新增「设置 · 升级包直链」 — 在「设置 → 检查新版本」页底部显示官方更新包下载地址，点击可复制（Hook 目标 com.xtc.setting）。
3.新增「应用中心增强」 — 去除应用中心安装限制，并在应用详情页显示下载直链 + 复制按钮（Hook 目标 com.xtc.appupdate / com.xtc.watchappstore）。
4.一键激活新增「重新激活」按钮 — 已激活状态下也能强制重跑完整激活流程，不再只能点「完成」。
5.作用域支持「全部已安装应用」 — 新增开关（默认开），激活时自动把设备上所有已装应用写入作用域。
6.新增「重新勾选设备上所有应用」按钮 — 在自激活页，点击重新枚举已安装应用并提示数量。
7.修复公告末尾出现「□/CR」方块。
8.「修复手动旋转屏幕」改为默认勾选。
9.Xposed API 版本调整为 89（1.0.0 为 93），兼容对应的 LSPosed / EdXposed / Vector 版本。
