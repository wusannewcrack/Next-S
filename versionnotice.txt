1.0.0 更新日志：
1.移除原版激活/解锁限制（删除 UnlockActivity、设备码、激活请求逻辑），所有功能开关无需激活码，直接可切换。
2.界面全面重构：改为 4 个横向板块（功能 / 应用设置 / 设置 / 核心破解设置）+ 顶部指示点导航。
3.新增一键自激活：自动适配 LSPosed / Vector / EdXposed，自动启用模块并写入作用域（含桌面 com.xtc.i3launcher）。
4.新增核心破解设置板块：在原有「原生包管理器去除检测 / 禁用 SDK 限制」基础上，扩展出「允许降级安装 / 绕过签名校验」（由新增 CorePatchHook 在 system_server 真实生效）。
5.新增 6 套主题配色（青蓝 / 纯白 / 深色 / 薄荷 / 樱粉 / 紫罗兰），可实时切换。
6.检查更新与公告更新。
7.应用设置新增「杀死后台应用」，root 强杀真实运行进程（原版无此功能）。
8.Xposed API 升级至 93，兼容最新 LSPosed / Vector / EdXposed（原版为 54）。
9.新增模块激活状态实时检测（设置页显示，杜绝原版误报）。
10.修复原版在手表上系统 Switch 不显示的问题，改为自绘开关。
