1.0.0 更新日志：
1.移除激活/解锁限制 — 删除原版 UnlockActivity、设备码、激活请求逻辑，所有功能开关无需激活码，直接可切换。
2.界面全面重构 — 改为 4+1 个横向板块（功能 / 应用设置 / 设置 / 核心破解设置 / 重启）+ 顶部指示点导航。
3.新增一键自激活 — 自动适配 LSPosed / Vector / EdXposed，自动启用模块并写入作用域（含桌面 com.xtc.i3launcher）。
4.新增核心破解设置板块 — 在原有「原生包管理器去除检测 / 禁用 SDK 限制」基础上，扩展「允许降级安装 / 绕过签名校验」（由 CorePatchHook 在 system_server 真实生效）。
5.新增 6 套主题配色（青蓝 / 纯白 / 深色 / 薄荷 / 樱粉 / 紫罗兰），可实时切换。
6.检查更新与公告更新。
7.应用设置新增「杀死后台应用」 — root 强杀真实运行进程（原版无此功能）。
8.Xposed API 升级至 93，兼容最新 LSPosed / Vector / EdXposed（原版为 54）。
9.新增模块激活状态实时检测（设置页显示，杜绝原版误报）。
10.修复原版系统 Switch 不显示，改为自绘开关 ToggleView。
11.修复开关点不动 — ToggleView 补 setClickable(true)，点击正常触发切换。
12.「返回上一板块」改为平滑横向滑动（不再瞬移）。
13.核心破解设置板块去除说明文字，仅保留 4 个真实生效开关。
14.修复应用选择器「已选(0)」不刷新 — 选中/全选/清空时实时更新计数。
15.新增「重启」板块 — 重启到系统 / 重启到 BL / 重启到 REC / 软重启（setprop ctl.restart zygote）/ 重启到 FB，均走 su -c（需 root）。
16.公告点一下内联显示文字 — 不再跳浏览器，卡片内直接展开链接内容。
17.修复公告缓存陈旧 — 代理 proxy.gitwarp.top 会缓存 GitHub raw，新增 proxyNoCache（追加 ?_t=时间戳）破除缓存。
18.功能页新增「去除腕上视频限制」开关 — 按 WanBiliHook 方式（钩 com.stub.StubApp.attachBaseContext 取真实 ClassLoader，再钩 pc.d(String) 强制返回 true）实现，目标包 cn.luern0313.wristvideoplayer。
19.推荐作用域新增腕上视频 — 自激活时把 cn.luern0313.wristvideoplayer/0 写入作用域，让 Hook 能注入该进程。
